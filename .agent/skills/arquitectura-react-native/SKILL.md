# Arquitectura de React Native

Patrones listos para producción para el desarrollo de React Native con Expo, incluyendo navegación, gestión de estado, módulos nativos y arquitectura 'offline-first' (primero sin conexión).

## Usa esta habilidad cuando

- Comiences un nuevo proyecto de React Native o Expo.
- Implementes patrones de navegación complejos.
- Integres módulos nativos y APIs de la plataforma.
- Construyas aplicaciones móviles 'offline-first' (que funcionen principalmente sin conexión).
- Optimices el rendimiento de React Native.
- Configures CI/CD para lanzamientos móviles.

## No uses esta habilidad cuando

- La tarea no esté relacionada con la arquitectura de React Native.
- Necesites un dominio o herramienta diferente fuera de este alcance.

## Instrucciones

- Aclara los objetivos, restricciones y las entradas requeridas.
- Aplica las mejores prácticas relevantes y valida los resultados.
- Proporciona pasos accionables y verificación.
- Si se requieren ejemplos detallados, abre `resources/implementation-playbook.md`.
